# 번역 (i18n)

게임 화면 글자는 한국어 원문을 그대로 열쇠로 써서 언어별 사전에서 바꿔 끼웁니다. 게임 코드 안의 한국어는 고치지 않습니다.

- `en.json` : 영어 사전. `{ "한국어 원문": "번역" }`
- `{}`, `{v}` 는 숫자·이름이 들어가는 자리입니다. 개수를 지키고, 어순 때문에 순서를 바꿔야 하면 `{1}`, `{2}` 처럼 원문에서 몇 번째 자리인지 번호로 씁니다.
- `' · '`로 이어진 문구는 조각도 자동으로 사전에 들어갑니다.
- 용어는 `GLOSSARY.md`를 따릅니다.

## 새 언어 추가 (예: 일본어)

1. `en.json`을 `ja.json`으로 복사하고 값만 번역합니다(열쇠인 한국어는 그대로).
2. 게임 코드의 `KX_LANGS`에 `ja:'日本語'`를 넣고, 설정 화면 `#segLang`에 버튼을 하나 추가합니다.
3. 빌드할 때 `i18n/*.json`이 모두 `<script id="kxL10N">`에 들어갑니다.
4. `node tools/ui-check.cjs --all --lang ja`로 글자 넘침과 "번역 안 된 문구"를 확인합니다.

## 새 문구가 생겼을 때

`python3 tools/i18n-extract.py index.html keys.json`으로 게임 안의 한국어 문구 목록을 뽑아 사전에 없는 것만 번역해 넣습니다. 번역이 빠진 문구는 게임에서 `window.__kxMissing`에도 모입니다.

언어는 기기 언어를 따르고(한국어면 한국어, 그 밖은 영어), 설정 → 언어에서 바꿀 수 있습니다(바꾸면 다시 불러옴).

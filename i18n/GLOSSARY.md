# KX-1000 영어 번역 용어집 (모바일 타워 디펜스: 외계 부대를 벙커로 막는 게임)

반드시 이 용어로 통일:
- 외계행성 1000부대 막기 → Stop 1000 Alien Squads
- 부대 → squad / 벙커 → bunker / 사령부 → HQ / 방어선 → defense line
- 강화 → Upgrade (탭 이름·버튼) / 돌파 → Breakthrough / 연속 강화 → hold to upgrade
- 작전 교리 → doctrine / 특급 교리 → elite doctrine / 다시 뽑기 → Reroll
- 지휘관 → Commander / 모집 → Recruit / 모집권 → recruit ticket / 출전 중 → Deployed
- 코인 → Coins / 코어 → Cores / 광물 → minerals / 에너지 → Energy
- 구역 → Zone / 구역 확보 → Zone secured / 웨이브 → Wave / 처치 → kills (명사), defeat (동사)
- 소총병 → Rifleman / 저격병 → Sniper / 수리 드론 → Repair drone / 궤도 폭격 → Orbital strike
- 장벽 → Barricade / 탱크 → Tank / 포탑 → Turret / 전투기 → fighter / 전기 철조망 → electric wire
- 도감 → Codex / 기록 → Records / 미션 → Missions / 업적 → Achievements / 패스 → Pass
- 보급 → Supplies / 상점 → Shop / 기지 → Base / 전투 → Battle
- 방어전 → Defense / 지옥 방어전 → Hell Defense / 타이탄 → Titan / 보스 → Boss
- 일반 / 영웅 / 전설 → Common / Hero / Legend
- 항공뷰 / 원근뷰 / 근접뷰 → Top view / Angle view / Close view
- 전투 시작 → Start Battle / 다시 막기 → Retry / 로비로 → Lobby / 계속 → Resume / 일시정지 → Paused
- 긴급 수리 → Quick repair / 철거 → Demolish / 내보내기 → Send out / 판매 → Sell / 대기 → waiting
- 전투력 → Power / 권장 → recommended / 여유 / 빠듯 / 위험 → Safe / Tight / Danger
- 광고 → Ad / 무료 → Free / 받기 → Claim
- 적 종족 이름(고유명사): 자르곤 → Zargon, 테리아 → Theria, 소포이 → Sophoi. 그 밖의 적·지휘관 이름은 자연스러운 영어 이름이나 소리 나는 대로(예: 레드 아이 → Red Eye, 모건 하사 → Sgt. Morgan).

규칙:
- 화면이 좁은 모바일 UI다. 짧고 자연스럽게. 버튼·탭·라벨은 1~3단어. 원문보다 크게 길어지지 않게.
- {} 와 {v} 는 숫자나 이름이 들어갈 자리. 개수를 그대로 지킨다. 영어 어순 때문에 순서를 바꿔야 하면 {1} {2} 처럼 원문에서 몇 번째 자리인지 번호로 쓴다(원문에 {}가 3개면 {1},{2},{3}). 순서가 같으면 {} 그대로.
- ' · ' (가운데 점) 구분, 숫자, %, +, ×, ÷, 기호, 이모지·특수문자(✓ ▾ » ⟳ 등)는 그대로 둔다.
- 원문이 문장 조각(예: '사령부 승급 ·', '. 깊은 우주에서…')이면 조각 그대로 번역(앞뒤 기호 유지).
- 한국어 조사 때문에 생긴 조각(예: '{}코인 {}')도 자연스럽게: '{} coins {}'.
- 개발용 문구(FPS, WebGL, 텍스처 등)도 번역.
